# 01. App Inventory & Current Consent Rules
 
**Date:** 23 November 2026, mid-afternoon

## Current Consent Rules

- Users can approve any application requesting delegated permissions.
- There is no admin review of user consent.
- No alerts are generated when users approve applications.
- Application permissions require administrator approval.

<BR>

## Available Identity Controls

- Require admin approval for some or all applications.
- Allow user consent only for low-risk permissions from verified publishers.
- Remove application access for everyone or selected users.
- End a user's signed-in sessions.
- Alert when someone approves an application.

<BR>

## Permission Types

| Type | Meaning |
|---|---|
| Delegated | The application acts on behalf of the user who approved it. |
| Application | The application acts independently within its granted permissions, without a user signing in or completing MFA. |
